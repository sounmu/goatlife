# 2026년 9월 챌린지 사진 운영

## 적용 전
- `/privacy`, `/photo-rules` 문구를 확인하고 개인정보 담당자의 성명/직책, 외부 수탁자의 정확한 법인명·업무 및 국외 처리 여부를 확정해 보완한다. 현재 연락처는 기존 사이트 문의 창구를 사용했다.
- Supabase 한국(서울) 리전은 운영자의 확인에 근거한다. Vercel 호스팅 및 Web Analytics를 포함한 실제 처리 위탁·국외이전 여부는 별도로 확인한다.
- Vercel Production 환경변수에 충분히 긴 무작위 `CRON_SECRET`을 설정하고 배포한다. 이 저장소 변경만으로 운영 예약이 활성화되지는 않는다.
- Vercel Cron 목록에서 `/api/cron/delete-proof-images` 등록을 확인한다. 매일 UTC 15:00(한국시간 다음 날 00:00)에 실행하며, Hobby에서는 해당 시간대 내 실행될 수 있다. 2026-10-04 한국시간 이전에는 삭제를 건너뛴다.
- 배포 전 `supabase/migrations/202609050001_photo_consent.sql`을 적용한다. 이전 인증에는 동의 기록을 소급 생성하지 않는다.
- 기존 참가자에게 변경된 사진 처리방침을 안내하고, 기존 사진에 필요한 동의를 별도로 확인한다. 새로운 업로드의 동의가 과거 사진에 자동 적용되지는 않는다.

## 10월 4일 삭제 확인
- 대상: `proof-images/11111111-1111-4111-8111-111111111111/` 하위 파일 전체. 다른 챌린지나 보증금 정산 데이터는 삭제하지 않는다.
- Storage API `remove`로 실제 파일을 삭제한다. DB 메타데이터만 삭제하는 방식은 사용하지 않는다. 고아 업로드도 폴더를 순회하여 삭제한다.
- 완료 로그 `campaign-photo-cleanup`과 `{skipped:false,deleted:N}`을 확인하고 대상 폴더가 비었는지 확인한다. 날짜·담당자·결과를 운영 기록에 남긴다.
- 실패/시간초과 시 당일 인증된 엔드포인트를 재호출한다. 정기 실행은 다음 날에도 재시도하므로, 당일 삭제 약속을 지키려면 운영자가 10월 4일 결과를 확인해야 한다. 삭제 재실행은 안전하다.
- 운영자 다운로드, 별도 백업 및 다른 서비스로 복사한 파일은 별도로 삭제한다. Supabase DB 백업에는 Storage 파일 본문이 포함되지 않는다.
- 사진 URL은 10월 4일 00:00 KST부터 410을 반환하고 신규 업로드도 차단된다. 이 접근 제한 자체가 실제 파일 삭제를 대신하지는 않는다.
- 사진 외 개인정보와 인증/정산 기록은 정책에 따라 정산·이의제기 종료 후 30일 이내 별도로 정리한다. 이 Cron은 사진 파일만 삭제한다.
