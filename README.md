# GOAT.MORNING

지금 신청을 받고 9월 6일부터 참여자별로 14일 동안 진행하는 보증금 기반 습관 챌린지 MVP입니다. 9월 6일 전 신청자는 9월 6일에 시작하고, 이후 신청자는 신청 다음 날 시작합니다. 참가자는 아침 미션과 날짜별 랜덤 미션을 각각 인증할 수 있습니다.

완주자 전원에게 로테이션 소개팅 참여 1만원 할인 쿠폰을 제공하고, 완주자 중 5명을 추첨해 커피를 선물합니다. 랜덤 미션 완료 횟수가 많을수록 커피 추첨 당첨 확률이 높아집니다.

## 핵심 구조

- Next.js 16 App Router + TypeScript + Tailwind CSS
- Supabase PostgreSQL + private Storage
- Server Actions 중심의 데이터 변경, Route Handler 기반 private 이미지 전달
- 환경변수 기반 단일 관리자 인증
- `Asia/Seoul` 기준 인증 시간과 실패 횟수 계산

서버만 Supabase service-role key를 사용합니다. 브라우저는 Supabase에 직접 접근하지 않으며 RLS에는 공개 정책을 두지 않았습니다.

## 로컬 실행

1. `.env.example`을 `.env.local`로 복사하고 값을 채웁니다.
2. Supabase 마이그레이션을 파일명 순서대로 모두 실행합니다.
3. `supabase/seed.sql`을 실행해 9월 4일–13일 신청, 9월 6일 순차 시작 챌린지와 날짜별 랜덤 미션을 만듭니다.
4. `npm run dev`로 시작합니다.

```bash
npm install
npm run dev
```

환경변수 없이도 랜딩과 신청 화면의 디자인은 확인할 수 있지만 신청 저장, 로그인, 인증, 관리자는 Supabase 연결 후 동작합니다.

## 주요 경로

| 경로 | 용도 |
| --- | --- |
| `/` | 랜딩 |
| `/apply` | 참가 신청 |
| `/apply/complete` | 계좌이체 안내 |
| `/join/[token]` | 개인 링크 자동 로그인 |
| `/login` | 전화번호 + 참가코드 로그인 |
| `/feed` | 전체 또는 친구 인증 피드 |
| `/proof/new` | 아침 미션과 오늘의 랜덤 미션 인증 |
| `/friends` | 친구 링크 공유와 친구 목록 |
| `/me` | 내 진행 현황 |
| `/admin` | 입금·참가자·인증 관리 |

## 운영 메모

- 입금 확인 시 참가 링크와 6자리 참가코드가 화면에 한 번 표시됩니다. 전달 문구를 편집한 뒤 Mac 문자 앱으로 복사해 보낼 수 있습니다.
- iPhone에서 모르는 발신자의 링크가 비활성화되면 발신자를 연락처에 추가하거나 메시지에서 `알려진 사람으로 표시`해야 합니다.
- 인증 이미지는 private bucket에 저장되고 로그인한 동일 챌린지 참가자 또는 관리자에게만 전달됩니다.
- 미라클 모닝 사진은 브라우저 안 카메라로 즉시 촬영해야 하며, 랜덤 미션은 즉시 촬영과 앨범 업로드를 모두 지원하고 사진만으로도 제출할 수 있습니다.
- 인증 직후 사진·날짜·미션이 담긴 인증 카드를 PNG로 저장하거나 모바일 공유 시트로 보낼 수 있습니다.
- 친구 링크를 받은 같은 챌린지 참가자는 로그인 후 확인을 거쳐 상호 친구가 되며, 피드에서 친구 게시물만 모아볼 수 있습니다.
- 인증 이미지는 브라우저에서 1MB 이하 WebP로 자동 압축되며, 서버와 Storage에서도 같은 제한을 적용합니다.
- 개인 시작일은 9월 6일과 신청 다음 날 중 더 늦은 날이며, 시작일을 포함한 14일째가 개인 종료일입니다.
- 관리자 화면의 `상태 판정 갱신` 버튼이 현재 유효 인증을 기준으로 성공/실패 상태를 갱신합니다.
- 실패 규칙은 챌린지의 `failure_rule`을 `AT_OR_ABOVE` 또는 `ABOVE`로 바꿔 조정할 수 있습니다.
